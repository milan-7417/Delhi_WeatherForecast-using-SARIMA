## 📌 Overview

**SkyCast Delhi** is a statistical weather forecasting web application that combines **real-time weather observations** with **locally generated 20-day weather forecasts**.

Unlike conventional weather dashboards that simply display forecast results obtained from external weather forecasting services, SkyCast Delhi generates its own future predictions using **SARIMA (Seasonal AutoRegressive Integrated Moving Average)** models trained on historical weather observations.

The application uses **Open-Meteo** as a data source for current weather observations, historical weather observations, and air-quality information. Future weather predictions are generated by the application's own statistical forecasting pipeline.

# 🤖 SARIMA Forecasting

**SARIMA** stands for:

> Seasonal AutoRegressive Integrated Moving Average

SARIMA is a statistical time-series forecasting model capable of modelling:

- Autoregressive relationships
- Moving-average relationships
- Trend
- Differencing
- Seasonal patterns

The general model formulation is:

```text
SARIMA(p, d, q)(P, D, Q, s)
```

Where:

| Parameter | Description |
|---|---|
| `p` | Autoregressive order |
| `d` | Degree of differencing |
| `q` | Moving-average order |
| `P` | Seasonal autoregressive order |
| `D` | Seasonal differencing |
| `Q` | Seasonal moving-average order |
| `s` | Seasonal period |

# 📊 Model Evaluation

The forecasting models are evaluated using standard statistical metrics.

### Mean Absolute Error — MAE

Measures the average absolute difference between actual and predicted values.

### Root Mean Squared Error — RMSE

Measures prediction error while giving greater weight to larger errors.

### Mean Absolute Percentage Error — MAPE

Measures prediction error relative to the actual values.

Evaluation results are stored in:

```text
models/training_results.csv
```

```text

 │
 ▼
Nginx :443
 │
 ▼
127.0.0.1:8000
 │
 ▼
FastAPI / Uvicorn
 │
 ▼
SkyCast Delhi
 │
 ▼
SARIMA Forecast
```

Nginx acts as a **reverse proxy**, receiving public HTTPS requests and forwarding them to the FastAPI application running locally on the EC2 instance.

The FastAPI application is managed by **systemd**, allowing it to continue running after the SSH terminal is closed and automatically start again when the EC2 instance is rebooted.
