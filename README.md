# 🌦️ SkyCast Delhi — Statistical Weather Forecasting using SARIMA

SkyCast Delhi is a statistical weather forecasting web application that combines **live weather observations** with **locally computed 20-day weather forecasts**.

Unlike conventional weather dashboards that simply display forecasts returned by external weather APIs, **SkyCast computes its own forecasts using SARIMA (Seasonal AutoRegressive Integrated Moving Average) models trained on historical weather observations.**

Current weather conditions are retrieved from Open-Meteo, while all future weather predictions displayed in the dashboard are generated by the application's own forecasting pipeline.

# 📌 Project Highlights

---

# ⚠️ Important Note

This project **does not use any weather forecasting API** for future predictions.

The Open-Meteo APIs are used only for:

- Current weather observations
- Historical weather data used for model training
- Air Quality Index (AQI)

The **20-day forecast shown in the application is computed locally using SARIMA models**, making the forecasting process independent of external forecast services.

# Forecast Generation Workflow

### Step 1

Download historical weather observations from the Open-Meteo Archive API.

↓

### Step 2

Prepare and clean the historical dataset.

↓

### Step 3

Train independent SARIMA models for each weather parameter.

↓

### Step 4

Generate a computed 20-day weather forecast.

↓

### Step 5

Cache forecast results for efficient API responses.

↓

### Step 6

Display live weather conditions together with the computed forecast.

# Model Evaluation

Each forecasting model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)

Evaluation results are automatically stored in:

```
models/training_results.csv
```

# Installation

Clone the repository:

```bash
git clone https://github.com/milan-7417/Delhi_WeatherForecast-using-SARIMA.git


cd skycast-delhi
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Train the forecasting models:

```bash
python training/train.py
```

Run the application:

```bash
uvicorn api.main:app --reload
```

Open the application:

```
http://127.0.0.1:8000
```
